# minitalk – 42 Project

---

# 🇫🇷 Français

## 📖 Introduction
**Minitalk** est un projet de 42 où il faut créer un petit programme de communication entre un **serveur** et un **client**, en utilisant uniquement les **signaux UNIX** (`SIGUSR1`, `SIGUSR2`).  
Ce projet m’a appris à travailler avec la **communication interprocessus (IPC)** et à mieux comprendre le fonctionnement des signaux.

---

# 🇬🇧 English

## 📖 Introduction
**Minitalk** is a 42 project where we create a small communication program between a **server** and a **client**, using only **UNIX signals** (`SIGUSR1`, `SIGUSR2`).  
This project taught me how **interprocess communication (IPC)** works and gave me a deeper understanding of UNIX signals.
